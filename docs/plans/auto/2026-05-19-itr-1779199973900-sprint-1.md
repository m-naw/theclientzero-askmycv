## Risk flags

- RF1: src/routes/admin.ts handleAdminReset error re-render (Fix 4A) must reconstruct a complete prefill object from loadConfig — if config is null (edge case: reset after config was already deleted), the re-render will fail. Guard: only attempt re-render when loadConfig returns non-null; fall back to bare 400 if null.
- RF2: admin-form.ts successMessage injection uses string replacement on rendered HTML (`configHtml.replace('<header>', ...)`). If future renderLayout changes ever remove the <header> tag, this injection silently no-ops. Note in code comment that this is a brittle pattern and should be revisited if renderLayout template changes.
