### Step 4

Rewrite the first test ('Worker /admin accepts a valid JWT and rejects a forged one') to seed a signing secret and session cookie, then include the session cookie in both fetch calls alongside the JWT.

The updated test must:
1. Seed KV with the full config (same as before, keep access_email: 'owner@example.com').
2. Seed KV with the JWKS document (same as before).
3. Store a fixed signing secret in KV under 'cookie_signing_secret'.
4. Create a signed session token using signSession({sub:'admin', iat: nowSec, exp: nowSec+86400}, secret).
5. Build a Cookie header value: `${SESSION_COOKIE_NAME}=${token}`.
6. For the valid-JWT request: include BOTH `CF-Access-JWT-Assertion: validJwt` AND `Cookie: sessionCookie` headers → expect 200.
7. For the forged-JWT request: include BOTH `CF-Access-JWT-Assertion: forgedJwt` AND `Cookie: sessionCookie` headers → expect 403.

Complete replacement for the test body:
```typescript
it("Worker /admin accepts a valid JWT and rejects a forged one", async () => {
  const jwks = await createJwksMock();
  const kv = (env as { STATE: KVNamespace }).STATE;

  await kv.put("config", JSON.stringify({
    display_name: "Test Owner",
    headline: "Test headline",
    cv_markdown: "# Test CV\n\nSome content.",
    anthropic_api_key: "sk-ant-smoke-key",
    daily_budget_usd: 5,
    access_email: "owner@example.com",
    access_aud: "aud-123",
    access_team_domain: "team.cloudflareaccess.com",
    setup_timestamp: Date.now() - 10000,
  }));
  await kv.put(TEST_JWKS_KV_KEY, JSON.stringify(await jwks.getJwks()));

  // Seed session cookie
  const signingSecret = "test-cookie-signing-secret-32b!";
  await kv.put("cookie_signing_secret", signingSecret);
  const nowSec = Math.floor(Date.now() / 1000);
  const sessionToken = await signSession({ sub: "admin", iat: nowSec, exp: nowSec + 86400 }, signingSecret);
  const sessionCookie = `${SESSION_COOKIE_NAME}=${sessionToken}`;

  const validJwt = await jwks.issueJwt({
    aud: "aud-123",
    iss: "https://team.cloudflareaccess.com",
    email: "owner@example.com",
  });
  const forgedJwt = await jwks.issueJwt({
    aud: "aud-123",
    iss: "https://team.cloudflareaccess.com",
    email: "owner@example.com",
    forge: true,
  });

  const ctxA = createExecutionContext();
  const validRes = await worker.fetch(
    new Request("https://example.test/admin", {
      headers: {
        "CF-Access-JWT-Assertion": validJwt,
        "Cookie": sessionCookie,
      },
    }),
    env as never,
    ctxA,
  );
  await waitOnExecutionContext(ctxA);
  expect(validRes.status).toBe(200);
  const validHtml = await validRes.text();
  expect(validHtml).toContain('name="cv_markdown"');

  const ctxB = createExecutionContext();
  const forgedRes = await worker.fetch(
    new Request("https://example.test/admin", {
      headers: {
        "CF-Access-JWT-Assertion": forgedJwt,
        "Cookie": sessionCookie,
      },
    }),
    env as never,
    ctxB,
  );
  await waitOnExecutionContext(ctxB);
  expect(forgedRes.status).toBe(403);
});
```

### Step 5

Rewrite the second test ('Worker /admin returns 403 when the CF-Access-JWT-Assertion header is absent') to reflect the new auth model: with a valid session cookie AND access_email configured, a request without a JWT returns 403.

Complete replacement for the test body:
```typescript
it("Worker /admin returns 403 when the CF-Access-JWT-Assertion header is absent", async () => {
  const kv = (env as { STATE: KVNamespace }).STATE;

  // Seed config with access_email so CF Access JWT is required as second layer
  await kv.put("config", JSON.stringify({
    display_name: "Test Owner",
    headline: "Test headline",
    cv_markdown: "# Test CV\n\nSome content.",
    anthropic_api_key: "sk-ant-smoke-key",
    daily_budget_usd: 5,
    access_email: "owner@example.com",
    access_aud: "aud-123",
    access_team_domain: "team.cloudflareaccess.com",
    setup_timestamp: Date.now() - 10000,
  }));

  // Seed a valid session cookie (layer 1 passes)
  const signingSecret = "test-cookie-signing-secret-32b!";
  await kv.put("cookie_signing_secret", signingSecret);
  const nowSec = Math.floor(Date.now() / 1000);
  const sessionToken = await signSession({ sub: "admin", iat: nowSec, exp: nowSec + 86400 }, signingSecret);
  const sessionCookie = `${SESSION_COOKIE_NAME}=${sessionToken}`;

  const ctx = createExecutionContext();
  const res = await worker.fetch(
    new Request("https://example.test/admin", {
      headers: { "Cookie": sessionCookie },
    }),
    env as never,
    ctx,
  );
  await waitOnExecutionContext(ctx);
  // Session valid but no JWT → 403 (CF Access layer rejects)
  expect(res.status).toBe(403);
});
```

**Verification:** The test now seeds config+session and sends only Cookie (no JWT header); expects 403.
