**Sprint ID:** ITR-1779128299196-sprint-1

## Context

G6: Inline recovery pages with verified Cloudflare dashboard navigation. Expands error/recovery views with self-contained step-by-step instructions and converts the POST /setup expired-window response from 410 HTML to 403 JSON.

## Risk flags

- RF1: SETUP_WINDOW_MS import into error-pages.ts is new — verify no circular dependency via state/machine.ts. Evidence: setup.ts already imports it (line 27) with no circularity, so risk is LOW.
- RF2: GET /setup expired path (separate block rendering 403 HTML) must NOT be changed — only the POST window-expired gate changes. Adversarial guard: step 1 explicitly scopes the replacement and the structural verification checks `! grep 'status: 410'` (which should only match the POST path that is being changed, not the GET path which already returns 403).

**Type:** code (modelTier: 2)

### Step 1

In src/views/error-pages.ts: add `import { SETUP_WINDOW_MS } from '../state/machine';` at the top (after existing imports). Change the function signature of renderExpiredSetup to accept `setupWindowStart?: string | number` so we can compute the UTC expiration. Inside the function, compute the expiration timestamp: `const startMs = props.setupWindowStart ? Number(props.setupWindowStart) : null; const expiredAt = (startMs && Number.isFinite(startMs)) ? new Date(startMs + SETUP_WINDOW_MS).toISOString() : null; const expiredAtHtml = expiredAt ? `<p class="muted">This window expired at <code>${expiredAt}</code> UTC.</p>` : '';`. Replace the static `start` variable with one that also shows the raw start: `const startDisplay = props.setupWindowStart ? `<p class="muted">setup_window_start was recorded at <code>${escapeHtml(String(props.setupWindowStart))}</code>.</p>` : '';`.

```typescript
const expiredAt = new Date(startMs + SETUP_WINDOW_MS).toISOString();
return new Response(
  JSON.stringify({
    error: "setup_window_expired",

    recovery_summary:

);
```
