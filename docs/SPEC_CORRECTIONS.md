# Spec Corrections

This file records corrections to published specifications. Each entry documents what changed, why, and which spec was affected.

---

## Template

Use the following structure to record a correction. Copy the block, fill in each field, and remove the placeholder text.

```
### [CORRECTION-NNN] <Short title>

**Date**: YYYY-MM-DD
**Affected spec**: docs/specs/auto/<filename>.md (or path to the spec file)
**Correction**: <Exact description of what changed. Be specific: what the old text said, what the new text says.>
**Reason**: <Why the correction was necessary. Reference evidence where possible: test name, command output, external source.>
```
